# Othmane Esijelmassi — Academic Website

A minimal, static academic website intended for GitHub Pages. All public-facing content is in English.

## Structure

```
index.html       Home / About
research.html    Research projects
reading.html     Academic reading notes
cv.html          Education and CV placeholder
assets/style.css All typography, colors, layout, responsive rules
.nojekyll        Publish static files directly
```

## Preview locally

Double-click `index.html` to open it in your browser. Links between pages work without installing software.

## Publish with GitHub Pages

1. Create a **public** GitHub repository called `<your-exact-GitHub-username>.github.io`.
2. Upload the CONTENTS of this folder at repository root (not the folder itself). Preserve `assets/style.css`.
3. Go to **Settings → Pages → Build and deployment**.
4. Select **Deploy from a branch**, then **main** and **/(root)**, and **Save**.
5. Your site will be available at `https://<your-exact-GitHub-username>.github.io/` after deployment.

Note: publishing makes this site public. Review names, email address, project descriptions and approval/confidentiality before deployment.
