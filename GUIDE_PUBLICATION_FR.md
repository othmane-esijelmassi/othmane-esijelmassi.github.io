# Guide rapide — publication de la charpente

Le site fonctionne déjà en local : ouvre `index.html` dans ton navigateur.

## Mise en ligne

1. Sur GitHub, crée un dépôt **Public** nommé exactement `TON-USERNAME.github.io`. Remplace `TON-USERNAME` par ton véritable identifiant GitHub.
2. Clique sur **Add file → Upload files**. Charge les 4 fichiers `.html`, le fichier `.nojekyll`, et le dossier `assets` avec `style.css` (en conservant l'arborescence). Tu peux aussi téléverser le contenu du dossier extrait d'un seul coup si ton navigateur le permet.
3. Valide avec **Commit changes**.
4. Va dans **Settings → Pages**. Sous **Build and deployment**, choisis **Deploy from a branch**, puis **main / (root)**. Clique **Save**.
5. Après déploiement, ouvre `https://TON-USERNAME.github.io/`.

**Attention :** le site deviendra public. Relis les informations personnelles et les intitulés de projets avant de publier.

## Pour modifier le contenu

- Page d'accueil : `index.html`
- Recherche : `research.html`
- Lectures : `reading.html`
- CV : `cv.html`
- Apparence de toutes les pages : `assets/style.css`

Le projet GDN n'est volontairement pas décrit en détail. Il faut obtenir les autorisations utiles et vérifier les résultats avant de partager davantage.
